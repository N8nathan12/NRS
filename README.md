# Instructions to install the program.
#### 1. Click on the program  zip folder you want to install(NS File directory).
#### 2. Once in, download the zip folder by either clicking 'view raw' or 'Download raw files' in the top right hand corner.
#### 3. After, the zip folder that has just been downloaded and extract it
#### 4. In the Extracted folder you should see 4 files don't run them all.
#### 5. Run the file with the cd disk icon and with the name 'Setup'.

## Alternate install.
#### 1. If you don't wan to download(understandable) you can clone the repository.
#### 2. To do this the only method i know how is to first install git.
#### 3. In developer command prompt(built into windows) have the directory you want the files to go into selected.
#### 4. Gather the link to the repository, you can use the link you pressed earlier or on the repository's main page click the green code button.
#### 5. Copy the Link from the locations from step 4.
#### 6. Go back on the developer command prompt and type 'git clone link(the link you copied)'.
#### 7. This will add a folder named NRS in the directory you had selected in Command prompt.
#### 8. Open the NRS folder and select the project and version you want.
#### 9. Extract the zip folder, then run the file wit the cd icon named 'setup'.
#### 10. Now the app is installed in your users account.

# Uninstalling.
#### 1. For uninstalling, open setting.
#### 2. Navigate to 'installed apps'.
#### 3. Find 'NS File directory'.
#### 4. Click on the 3 don'ts to the right, and click uninstall.
